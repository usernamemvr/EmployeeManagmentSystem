## 🚀 Employee Management System (EMS)

A full-stack web application to manage employee records. Built with **React** for the frontend, **Java (Spring Boot)** for the backend, and **PostgreSQL** for the database.

### 📌 Features
- Add, update, view, and delete employees
- Clean and responsive UI
- RESTful APIs with proper validation and error handling

### 🛠️ Tech Stack
- **Frontend:** React, Bootstrap, Axios, React Router
- **Backend:** Java, Spring Boot, REST API, Java 8, Spring JPA
- **Database:** PostgreSQL

### 📂 Project Structure
```
backend/
 └── src/main/java/...         # Spring Boot Application
frontend/
 └── src/                     # React Components
```

### ⚙️ How to Run

#### 1. Clone the Repo
```bash
git clone https://github.com/yourusername/ems-project.git
cd ems-project
```

#### 2. Backend (Spring Boot)
- Configure PostgreSQL credentials in `application.properties`
- Run the Spring Boot app

#### 3. Frontend (React)
```bash
cd frontend
npm install
npm start
```
